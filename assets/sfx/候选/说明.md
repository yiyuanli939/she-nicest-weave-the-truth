# 候选音效方案(试听后告诉我用哪套 / 哪几个)

每套一个文件夹,文件名 = 槽位名(`_2`/`_3` 是同一槽位的备选);本目录有 `.gdignore`,引擎不导入、不进导出包。
对比页(可直接试听、点选、复制结果):见会话里的 artifact 链接;也可以在文件夹里逐个听。
选定后:把选中的文件复制到 `assets/sfx/<槽位>.ogg`(或 .wav,`game/sfx.gd` CLIPS 改后缀),`--import`,跑 `tools/sfx_audit.py` 更新 `GAIN_DB`。

|---|---|---|
| K_Kenney现用 | 通用界面音,已按频谱挑最柔和的 | Kenney CC0(`../LICENSE-kenney.txt`) |
| A_黄铜机械 | 金属 / 木头 / 机械件:黄铜按钮、闩锁、齿轮、木叩 | freesound.org,全部 CC0(逐文件见下) |

筛选:每个槽位先按下载量取前几名,再按「不刺耳」量化(频谱质心、4 kHz 以上能量占比、峰值因子)排序取最柔和的。
下表 H = 刺耳度分数(越低越柔和,≤ 4 为柔和),dur = 秒。
