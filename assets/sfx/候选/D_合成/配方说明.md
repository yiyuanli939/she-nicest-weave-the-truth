# 候选 D:Godot 自合成(不下载素材)

全部由 `tools/sfx_synth.gd` 用 Godot 的 `AudioStreamWAV` 拼 PCM 合成,`tools/gen_sfx.gd` 落盘;没有任何外部素材,没有版权问题。
重出全套(1 s):

```bash
"$GODOT" --headless --path . --script res://tools/gen_sfx.gd            # 全部
"$GODOT" --headless --path . --script res://tools/gen_sfx.gd -- click win   # 只重出这几个
```

响度已统一(RMS -18 dBFS、峰值 ≤ -1 dBFS),`sfx_audit.py` 的 GAIN_DB 建议值都在 0 附近;想让某个槽位更轻(悬停、警告、指引)在 GAIN_DB 里写意图即可。
改音色 = 改 `tools/sfx_synth.gd` 里对应的 `_r_<槽位>` 配方(材质:黄铜 `_brass` / 木叩 `_knock` / 木琴 `_wood` / 小铃 `_bell` / 织物纸张 `_noise`),
重出后 `tests/test_sfx_synth.gd` 会盯文件 = 配方。
