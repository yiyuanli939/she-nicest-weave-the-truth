# 操作音效槽位表

引擎按槽位名读 `assets/sfx/<槽位>.ogg`(也可 .wav);槽位 → 文件的对应表是 `game/sfx.gd` 的 `CLIPS`(`""` = 该处静音)。
换音效 = 覆盖同名文件(或改表里一行);响度不一在 `GAIN_DB` 按槽位填 dB。**做完 `godot --headless --path . --import`,
`.import` 和音频一起提交**;`tests/run_tests.gd` 会检查表里的文件都在、都是 ≤ 2 s 的短音(win ≤ 5 s)。

来源:用户 2026-09-02 在试听台从候选 A / B / C 里逐槽位挑定的 33 段 freesound CC0 + 1 段 Kenney CC0(unplug,`LICENSE-kenney.txt`),
逐文件的标题 / 作者 / 链接 / 许可见文末「现用文件与来源」表 —— **换文件必须同步补表,授权信息要跟着文件走**;候选库见 `候选/`。
挑选原则(用户 2026-09-02):**不要刺耳**。量化标准:频谱质心 < 3 kHz、4 kHz 以上能量占比 < 0.3、峰值因子 < 22 dB
(`tools/sfx_audit.py` 会把表里每个文件量一遍并报超标的)。

**同一帧同槽位只响一次**(多选删除、多条线同时断、多枚徽章同时出现)。

## 换音效

1. 把新文件放成 `assets/sfx/<槽位>.ogg`(或 .wav)覆盖;要几个槽位共用一个文件就改 `CLIPS` 指到同一路径。
2. `godot --headless --path . --import`;`hardware/.venv/bin/python tools/sfx_audit.py` 看响度 / 刺耳度,把建议的 dB 填进 `GAIN_DB`。
3. 跑 `tests/run_tests.gd`(表 / 文件 / 时长)和 `tests/visual_smoke_ui.gd`(每个挂点真的响)。
4. 在下面的来源表补一行。

## 现用文件与来源

- 34 段 Kenney CC0(Interface Sounds / UI Audio / Impact Sounds / Music Jingles),按槽位改名;`loom.ogg` = Kenney `scroll_003`(原 page)。
- `page.ogg`:freesound 「Page turn」 by chungus43A,CC0,https://freesound.org/people/chungus43A/sounds/705384/(候选 B 的 page)。

全部 CC0(freesound.org 的 CC0 1.0 / Kenney CC0),不要求署名,但这里保留每段的出处以备核查;候选库逐文件明细在 `候选/manifest.json` / `候选/说明.md`。
装入时做过统一处理(用户要求「保证音效声音的一致性」;脚本逻辑见 `docs/TUTORIAL.md` 3.9):全部转单声道 44.1 kHz Vorbis q6,
起始静音(峰值 -40 dB 以下)裁到 5 ms、尾部(峰值 -60 dB 以下)裁到 20 ms、2 ms 淡入 / 10 ms 淡出,RMS 归 -18 dBFS 且峰值 ≤ -1 dBFS
(与 `tools/sfx_audit.py` 同口径,所以 `GAIN_DB` 基本都是 0,只剩 hover -4 / win ≤ -5 的意图);音色没动。
共用文件的别名槽位:undo → back、unpin → close、pin_error → error、skip → zoom。
