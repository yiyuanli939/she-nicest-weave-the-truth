# 织理者 Textrix Veritatis — 展示文案

## 1. 作品 Slogan

在一间维多利亚织坊里,把丝线织成无可辩驳的纹样——你全程见不到一个逻辑符号,却在不知不觉中完成了一整套自然演绎证明。

(短版:「把『因为所以』织成看得见的纹样。」)

## 2. 游戏玩法说明

- **玩法**:每一关给你几卷「线轴」(已有的纹样)和一台「目标织机」(要交付的纹样)。从左侧仪器架取出黄铜仪器(并织机、拆股机、封程机、引渡机、岔纹机、汇路机、溃散机),摆上织案,把线轴的丝线经过仪器接到目标织机——每台仪器都会按自己的规矩把输入纹样加工成新纹样。
- **操作**:鼠标左键从仪器架放置仪器、拖动节点、在端口之间拉线;右键点仪器可拆除;有的仪器口需要你自己决定织什么,点它标题栏的「钉纹样」,用色块画一幅钉上去;右缘「笔记」抽屉随时可翻七台仪器的说明;Esc 返回。
- **交互(实体机器人「小机」)**:桌上的小机器人会迎接你、通关时仰头点头庆祝、接错线时鼓励你、发呆太久会给提示;对着麦克风说**「请指导我」或「请帮帮我」**,前两章它会回头看一眼屏幕然后替你把这一关织完(它不夸你);第三章它坏掉了,只会发出故障声乱动;第四章被你修好,再喊它就只回头看看你——剩下的路要自己织。
- **目标与通关**:让目标织机上织出与要求完全一致的纹样、且没有任何一条线报「冲突/欠定」,状态栏出现**「织成了!」**即通关,自动解锁下一关。全程 4 章 15 关(并纹 → 叠层纹 → 岔纹 → 焦纹),线性推进。

## 3. 项目说明

- **问题**:形式逻辑/自然演绎是大学逻辑与计算机课程的入门坎——符号密集、规则抽象,初学者往往在「∧∨→⊥」上就被劝退;而现有的教学工具(如 The Incredible Proof Machine)仍以裸逻辑符号面对学习者。
- **方案**:把自然演绎完整地「换皮」进一个维多利亚纺织世界:命题是纹样、推理规则是七台黄铜仪器、证明是从线轴到织机的一张织程图。游戏内**零逻辑符号、零逻辑术语**,玩家凭直觉学会每台机器的行为,实际上在做严格的正向自然演绎证明(引擎实现了公式合一、辖域检查与严格正向求解,拒绝任何反推作弊)。搭配一只实体桌面机器人作为情感支架:引导、庆祝、鼓励、求助代解,并用「第三章坏掉、第四章修好」的剧情把它织进故事。
- **现场完成内容**:可通关的完整游戏(4 章 15 关 + 开场剧情 + 美术整合:标题/选关/故事/关卡/笔记全套手绘 UI,站酷小薇体);实体机器人全链路(ESP32-S3 固件、串口-WebSocket 桥接、离线中文语音识别「请指导我/请帮帮我」、表情/云台/语音演出、游戏内维护面板可一键接入与刷写);台词 CSV 导入管线与自动化测试(96 项单元测试 + 三套端到端回归)。
- **使用方式**:小机接两根线(USB 通信 + DC 5–12V 供电),运行游戏 → 开发者信息 → 小机维护 → 「接入小机」;点「开始游戏」进选关,鼠标即玩;对小机说「请指导我」体验代解。
- **硬件要求(机器人部分必须使用专有硬件)**:实体交互依赖专用套件——小智 AI 桌面机器人(ESP32-S3 N16R8「emoji」底板:OLED 表情屏、双轴舵机云台、MAX98357A 功放与定制外壳),外加运行桥接与离线语音识别的电脑(macOS,含麦克风)。机器人供电必须走底板 DC 座(5–12V 适配器),USB 仅作通信;通用开发板/其他机器人无法直接替代(引脚、外设、动作与剧情演出均按这套硬件定制)。**没有该硬件时,游戏本体完全可玩**,所有机器人联动自动静默降级。
