> 对象:`levels/data/l01–l15`(由 `tools/gen_levels.gd` 的 `LEVELS` 表生成)。
> 数据来源:每关"最短解"取 `tests/level_solutions.gd`;提案关卡全部用纯 `ProofSession` API

> 原版对照:incredible.pm `sessions.yaml`(Session 1–4,本作无 TND)。

## 0. 怎么量化"难"

本作和原版最大的差别是**求解严格正向、自由纹样一律由玩家钉**。原版靠合一自动推出封程机的假设、
岔纹机的另一支;本作里这些都是玩家要"想出来并在编辑器里织出来"的东西。所以难度有四个独立的轴:

| 轴 | 含义 | 取值 |
|---|---|---|
| **操作量** | 机器数 + 连线数 + 钉数(最短解) | 1 … 16 |
| **钉复杂度** | 钉的纹样是原子 / 复合 / 含焦纹(⊥) | 无 → 原子 → 复合 → 含⊥ |
| **辖域复杂度** | 假设口的用法 | 无 → 自环 → 穿入内层 → 驱动链 → 双支路 → 跨机 |
| **概念负荷** | 本关**首次**要求的交互/逻辑技能数 | 理想是每关 ≤ 1 |

星级是这四轴的综合:★ 裸机 · ★★ 两三台配合 · ★★★ 有辖域或 ≥9 步 · ★★★★ ≥13 步或双辖域 · ★★★★★ 峰值/跨机辖域。

## 1. 现有 15 关逐关总结

### 第一章·并织(织坊 / 阿梭)

**l01 第一缕丝** `A ⊢ A` — 0 机 / 1 线 / 0 钉 = **1** ★
- 解:线轴直接连目标织机。
- 目的:学会拖线;建立"线轴 = 前提、织机 = 结论"的画面语言。
- 评注:合格的第 0 关。面板上已有并织/拆股两台机器但用不到,给玩家看一眼即可。

**l02 并织初试** `A, B ⊢ A & B` — 1 / 3 / 0 = **4** ★
- 解:两根线轴 → 并织机 → 目标。
- 目的:第一台仪器;双输入口**有序**(接反得到 `B & A`,目标织机亮骷髅)。
- 评注:接反是玩家第一次见错误徽章,是天然教学,不必额外提示。

**l03 左右互换** `A & B ⊢ B & A` — 2 / 4 / 0 = **6** ★★
- 解:拆股机拆开,交叉接回并织机。
- 目的:拆股机(双输出);两机串联;输出口也有序。
- 评注:恰好是"l02 接反"的解药——拆了再倒着并,呼应得好。

**l04 结绳记事** `A & (B & C) ⊢ (A & B) & C` — 4 / 7 / 0 = **11** ★★★ · 解锁 `notebook_and`
- 解:两台拆股拆到原子,两台并织按新括号并回。
- 目的:嵌套纹样读图(分割线粗细 = 嵌套级数);多机规划。章末综合。
- 评注:操作量是 l03 的近两倍,但全是已学概念,作章末合适。

### 第二章·封程(封程工房 / 莉娅)

**l05 引渡** `A, A > B ⊢ B` — 1 / 3 / 0 = **4** ★
- 解:迭层纹接引渡机上口,`A` 接下口。
- 目的:引渡机;两个输入口性质不同(一个要迭层纹,一个要它的上层)。
- 评注:面板同时出现封程机(本关无用),会诱导玩家去点"钉纹样"。建议新机器在它的裸机关才上架(见 §4.3)。

**l06 接力** `A > B, B > C ⊢ A > C` — 3 / 6 / 1 = **10** ★★★
- 解:封程机钉假设 `A`,假设口 → 引渡(`A>B`)→ 引渡(`B>C`)→ 回封程机输入口 → 目标。
- 目的:首次封程——钉假设、假设口回流、辖域、引渡链。
- 评注:**全游戏最大的曲线问题。** 一关塞进 4 个新概念(钉纹样按钮、假设口、"必须回到本机输入口"的辖域、
  引渡串联),而封程机的五行教学对话和 `notebook_imp_intro` 笔记在**下一关** l07。玩家在这里第一次看到"钉纹样",没人教。

**l07 自证** `⊢ A > A` — 1 / 2 / 1 = **4** ★ · 解锁 `notebook_imp_intro`
- 解:封程机钉 `A`,假设口接回自己的输入口。
- 目的:封程机裸机教学(五行引导对话);首次无前提关卡;最小的辖域用法(自环)。
- 评注:内容对、位置错——必须在 l06 之前。

**l08 层层封存** `⊢ A > (B > A)` — 2 / 3 / 2 = **7** ★★
- 解:外层钉 `A`、内层钉 `B`;外层假设口 → 内层输入口 → 内层输出 → 外层输入口。
- 目的:嵌套封程;外层假设可穿入内层子证明;内层假设 `B` **钉了不用**(弱化)。
- 评注:"钉了不用"是隐藏概念,全靠未钉口的幽灵纹样"?"提示玩家去钉;值得单独一关先教。

**l09 柯里化** `(A & B) > C ⊢ A > (B > C)` — 4 / 7 / 2 = **13** ★★★★ · 解锁 `notebook_imp`
- 解:双层封程各钉 `A`、`B`,两假设并织成 `A & B`,引渡前提得 `C`,逐层封回。
- 目的:章末综合:嵌套封程 + 并织 + 引渡。
- 评注:合理的章末峰值。

### 第三章·岔纹(档案室 / 档案员)

**l10 岔路** `A ⊢ A | B` — 1 / 2 / 1 = **4** ★
- 解:岔纹机上口钉另一支 `B`。
- 目的:岔纹机裸机;"钉另一支"。
- 评注:好。但只教了上口(输入在左);下口(输入在右)到 l11 才被迫使用。

**l11 殊途同归** `A | B ⊢ B | A` — 3 / 6 / 2 = **11** ★★★
- 解:汇路机两个假设口各接一台岔纹机(一台走下口钉 `B`,一台走上口钉 `A`),两支路回汇路机。
- 目的:汇路机——两支路、两假设口、两辖域;岔纹上下口各用一次;两处钉。
- 评注:汇路机**没有裸机关**,首用即 11 步、3 机 2 辖域,是第二个"l06 式"跳变。

**l12 两案并陈** `(A > C) & (B > C) ⊢ (A | B) > C` — 5 / 10 / 1 = **16** ★★★★★ · 解锁 `notebook_or`
- 解:封程机钉 `A | B`;假设口进汇路机;拆股得两张承诺;两支路各引渡得 `C`;汇路 → 封程 → 目标。
- 目的:章末综合:封程 + 汇路 + 拆股 + 双引渡。
- 评注:全游戏操作量峰值,**同时**首次要求在编辑器里织复合纹样(`A | B`)——两件难事撞在一关。

### 第四章·焦纹(焦纹禁室 / 档案员)

**l13 焦土** `⊥ ⊢ A` — 1 / 2 / 1 = **4** ★
- 解:溃散机钉 `A`。
- 目的:溃散机裸机;焦纹笔刷解锁。
- 评注:好。

**l14 逆否** `A > B ⊢ (B > ⊥) > (A > ⊥)` — 4 / 7 / 2 = **13** ★★★★
- 解:外层钉 `B > false`、内层钉 `A`;`A` 引渡得 `B`,再被 `B > ⊥` 引渡成 `⊥`;逐层封回。
- 目的:否定 = "蕴含焦纹";首次钉含 ⊥ 的复合纹样;双层封程。
- 评注:**不用溃散机**,和本章主题脱节;操作量高于章末 l15。

**l15 矛盾爆炸** `A & (A > ⊥) ⊢ B` — 3 / 5 / 1 = **9** ★★★ · 解锁 `notebook_bot` · glitch
- 解:拆股 → 引渡出 `⊥` → 溃散机钉 `B`。
- 目的:终章:矛盾生焦纹,焦纹织万物;小机 glitch 的剧情点。
- 评注:叙事位置对(提案里的高潮就是"前提错了→系统失控"),难度位置不对——比前一关轻,作全游戏终章偏薄。

## 3. 重设计原则

1. **新仪器三段式:裸机 → 配合 → 综合。** 每台机器第一次出现时只有它自己(≤ 5 步),再和旧机器配合,章末综合。
   封程机、汇路机这两台带假设口的机器各配一段引导对话(现有 l07 的五行式)。
2. **一关一个新概念。** 操作技能(一口多线、复合钉、含⊥钉、岔纹下口)各自单独占一关,不和逻辑概念撞车。
3. **章内单调上升,章首回落,全局峰值在末章。** 章内允许按"新仪器"分两段各自单调(第二章:引渡段 / 封程段)。
4. **钉复杂度、辖域复杂度各自独立爬坡**:原子 → 复合 → 含⊥;自环 → 穿入内层 → 驱动链 → 双支路 → 支路里溃散 → 跨机。
5. **呼应(echo)**:同一形状换语境——"引渡接力"(有 `A`)→"接力"(自己借 `A`);"会审"(三条线轴)→"两案并陈"(承诺被并织、岔纹成了假设)→"禁纹"(结论换成 ⊥)。
   玩家会认出形状,难度感知下降而成就感不降。
6. **叙事挂点不动**:4 章 4 地点 4 位说话人;笔记本在章末解锁;glitch 在末章。现有 15 关**全部保留**,只重排 + 插入 10 关。
